## What is Angular?
Angular is a TypeScript-based open-source web application framework that helps you build modern, scalable single-page applications (SPAs).

## Basic Languages in Angular

### 1. HTML (HyperText Markup Language)
- Provides the structure and content of your application
- Used to create component templates
- Works with Angular directives like `*ngIf`, `*ngFor`, `*ngSwitch`
- Example: Creating the layout and structure of your components

### 2. CSS (Cascading Style Sheets)
- Styles your Angular application
- Can be scoped to individual components
- Supports modern CSS features and preprocessors (SCSS, SASS, LESS)
- Example: Making your app beautiful and responsive

### 3. JavaScript/TypeScript
- Powers the logic and functionality of your application
- Angular uses TypeScript (a superset of JavaScript)
- Handles data binding, events, and business logic
- Example: Managing application state and user interactions

## Key Angular Concepts to Learn

1. **Components** - Building blocks of Angular applications
2. **Directives** - Add behavior to DOM elements
3. **Services** - Share data and logic across components
4. **Modules** - Organize your application
5. **Routing** - Navigate between views
6. **Data Binding** - Connect template and component
7. **Dependency Injection** - Manage dependencies efficiently
8. **Forms** - Handle user input
9. **HTTP Client** - Communicate with backend
10. **Observables** - Handle async operations
